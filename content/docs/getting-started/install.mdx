---
title: Install and pin the extension
description: Install Recordful from the Chrome Web Store and pin it to your toolbar in three steps.
---

Recordful is free and needs no sign-in to record.

1. Install Recordful from the Chrome Web Store.
2. Click the puzzle-piece extensions icon in the Chrome toolbar, then press the pin icon next to Recordful.
3. Click the Recordful icon to start. The popup opens where you pick what to record.

![Pin the extension to the toolbar](/pin.gif)

After pinning, the welcome popup walks you through your first recording. You can start from the popup in any tab.
