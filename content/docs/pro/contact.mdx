---
title: Contact support and report abuse
description: How to reach a human, what to attach, and how to report a shared recording.
---

- **Help and bugs:** use Having issues in the editor or the support button in the popup. Attach the diagnostic report download when asked. It has system info and session data, never video.
- **Email:** support@recordful.app. Data copies and deletion requests go here too (see the Privacy Policy).
- **Report a shared recording:** every shared page has a Report link. Include the recording ID from the email it drafts. There is not yet an automated takedown portal; reports are reviewed by hand.
