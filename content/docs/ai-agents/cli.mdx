---
title: Command line
description: "Use recordful-mcp from a terminal or any agent with a shell: record, upload, list videos and read transcripts, with JSON output."
---

The same abilities as the MCP tools, for people and agents that prefer a shell. To record a tab, click the Recordful icon on it first.

```bash
npx -y recordful-mcp start
npx -y recordful-mcp stop
npx -y recordful-mcp upload --title "Sign-up demo"
npx -y recordful-mcp transcript > transcript.txt
npx -y recordful-mcp videos
```

The first command may ask you to click the Recordful icon once to pair; after that Recordful connects by itself. A small background helper then keeps Recordful's connection for later commands and exits after 30 idle minutes.

## Commands

| Command | What it does | Plan |
| --- | --- | --- |
| `start [--tab <id>]` | Start recording with your Recordful settings | Free and Pro |
| `pause`, `resume` | Pause or resume | Free and Pro |
| `stop` | Stop; says where the recording went | Free and Pro |
| `screenshot [--page] [--look 3d\|<look>]` | Screenshot the tab and open it in Recordful's screenshot editor (`--page`: the whole page) | Free and Pro |
| `screenshot --source screen\|window\|area [--window <name>] [--display <n>] [--look 3d]` | Screenshot your computer with the [desktop app](/docs/desktop/screenshots) and open it in the app's editor. `--window`: part of a window's title or app name; `--display`: `1`, `2`… or `main`. Needs **Let AI agents take screenshots** on | Free and Pro |
| `windows` | List the windows the desktop app can screenshot | Free and Pro |
| `recordings` | Recordings saved on this computer | Free and Pro |
| `status` | Connection, recorder, account and pairing state | Free and Pro |
| `upload [<takeId>] [--title t] [--visibility private\|workspace\|public] [--force] [--no-wait]` | Upload a recording and print its links | Pro |
| `videos [--limit n] [--query text]` | List your videos | Pro |
| `video [<videoId>] [--wait]` | One video's links and upload stage | Pro |
| `transcript [<videoId>] [--format text\|vtt\|json] [--query <words>] [--no-wait]` | Print what was said; `--query` prints only the moments that mention it, with times | Pro |
| `summary [<videoId>] [--generate \| --regenerate]` | The AI summary and chapters; `--generate` writes one and spends about 2 AI credits | Pro |
| `update [<videoId>] [--title t] [--visibility private\|workspace\|public] [--password-stdin \| --no-password] [--expires <time> \| --no-expiry]` | Rename a video, change who may watch, or lock its link with a password (read from stdin, so it stays out of your shell history) or an end date | Pro |
| `activity [<videoId>] [--days n]` | Views (where from, per day), likes and comments | Pro |
| `analytics [--days n]` | Views per day across all your videos, and the most viewed | Pro |
| `comment [<videoId>] --body <text>` | Post a comment as you (public to viewers) | Pro |
| `comment-delete <videoId> <commentId> --yes` | Delete one comment for good | Pro |
| `like [<videoId>] [--undo]` | Like or unlike | Pro |
| `folders` | List your folders | Pro |
| `folder-create <name> [--parent <folderId>]` | Create a folder | Pro |
| `move <videoId>... [--to <folderId>]` | Move videos into a folder (no `--to`: the top level) | Pro |
| `delete <videoId> --dry-run \| --yes` | `--dry-run` shows what would go; `--yes` moves that exact video to trash for 7 days | Pro |
| `trash` | Deleted videos and when each is gone for good | Pro |
| `restore <videoId>` | Bring a video back out of trash | Pro |
| `members` | Who is in your workspace, and who is invited | Pro |
| `invite <email> --yes` | Invite someone to your workspace (owner only) | Pro |
| `storage` | Cloud storage used | Pro |
| `call <method> [json]` | Call one Recordful method directly, such as `page.click` | Free and Pro |
| `install --target <app> [--yes]` | Add Recordful to an AI app's configuration | none |
| `unpair [<id>\|--all]` | Forget a paired Recordful | none |
| `setup`, `prompt`, `guide --json` | Setup steps, the [setup prompt](/docs/ai-agents/setup-prompt), and a description of everything for agents | none |

Without a video or recording ID, commands use the last recording.

## Output and exit codes

- Add `--json` to any command for machine-readable output on stdout. Progress and hints go to stderr.
- Exit code `0` is success, `1` is a failure (the error code is in the message, for example `PRO_REQUIRED`), and `2` means a transcript isn't ready yet. That is not a failure: retry, or leave off `--no-wait`.

`npx -y recordful-mcp guide --json` prints tools, commands, error codes, plans and safety rules in one document. An agent should read that instead of relying on remembered commands.
