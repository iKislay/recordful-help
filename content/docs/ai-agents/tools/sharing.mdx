## `set_visibility`

**Pro.** Changes something; can remove or replace what is there. "private" (only the person who recorded it), "workspace" (members of the user's workspace) or "public" (anyone with the link). Making it public lets anyone with the link watch, so check with the user first. Only the person who recorded it, or the workspace owner, can.

**Parameters**

| Parameter | Type | Required | What it is |
| --- | --- | --- | --- |
| `videoId` | string | yes | The video's id (videoId from list_videos). |
| `visibility` | "private", "workspace", "public" | yes |  |


**Returns** `videoId`, `visibility`, `viewUrl` (The video's page on recordful.app), `editUrl` (Where the user edits it).

## `set_share_password`

**Pro.** Changes something; can remove or replace what is there. People outside the workspace must type this password to watch (members never do). null removes it. Use only a password the user gave you, never invent one. Returns whether it's locked, never the password.

**Parameters**

| Parameter | Type | Required | What it is |
| --- | --- | --- | --- |
| `videoId` | string | yes | The video's id (videoId from list_videos). |
| `password` | string or null | yes | The password; null removes it. |


**Returns** `videoId`, `passwordProtected` (People outside the workspace must type a password to watch), `linkExpiresAt` (ISO 8601, when the link stops working for people outside the workspace; null: never).
