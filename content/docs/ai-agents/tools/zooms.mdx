## `list_zooms`

**Pro.** Reads only. A Recordful video's zooms in order of time: each one's index, start and end in seconds as the video plays now, depth (scale, null for the video's zoomDepth), whether it follows the cursor or closes in on a fixed x, y, and its perspective (tilt, turn). The version is what update_zoom and remove_zoom need. Only the person who recorded it, or the workspace owner, can.

**Parameters**

| Parameter | Type | Required | What it is |
| --- | --- | --- | --- |
| `videoId` | string | yes | The video's id (videoId from list_videos). |


**Returns** `videoId`, `version` (The edit's version. Pass it as expectedVersion to apply edits only to the edit you read), `zoomDepth` (How many times closer a zoom with a null scale goes), `zooms` (Every zoom in order of time; index is what update_zoom and remove_zoom take), `viewUrl` (The video's page on recordful.app), `editUrl` (Where the user edits it).

## `add_zoom`

**Pro.** Changes something. Zoom in for a stretch. Without x and y it follows the pointer where its path was recorded, else it closes in on the middle. Fails if a zoom is already there. Times are seconds of the video as it plays now. Pass expectedVersion to apply only to the edit you read; edit_conflict means the edit changed meanwhile and nothing applied: list again and retry. Only the person who recorded it, or the workspace owner, can.
