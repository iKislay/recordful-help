Get a signed POST when a video is ready, viewed, transcribed or commented on. 5 tools.

## `list_webhooks`

**Pro.** Reads only. The workspace's webhooks, oldest first: URL, events and whether each is active. Secrets are shown only when one is made.

**Parameters**

None.


**Returns** `webhooks`.

## `create_webhook`

**Pro.** Changes something. Posts the workspace's chosen events to a URL of the user's. Answers the signing secret once: tell the user to keep it, it can't be read again. At most 10 per workspace. Each delivery is a POST of JSON &#123; id, type, createdAt, workspaceId, data &#125; where data.video is &#123; id, title, durationSeconds, viewUrl, editUrl &#125;; video.viewed adds data.view &#123; viewedAt, source, referrerHost, utmSource, utmMedium, utmCampaign, embedded, country &#125; and comment.created adds data.comment &#123; id, body, createdAt, author: &#123; name &#125; &#125;. Headers: Recordful-Event (the type), Recordful-Event-Id (the id, the same on every retry, to drop repeats) and Recordful-Signature: t=&lt;unix seconds>,v1=&lt;hex HMAC-SHA256 of "&lt;t>.&lt;raw body>" with the secret>; refuse a t older than 300 s. Answer 2xx within 10 s; anything else is retried up to 10 times with backoff.

**Parameters**

| Parameter | Type | Required | What it is |
| --- | --- | --- | --- |
| `url` | string | yes | Where to post: https, on a public host name. |
| `events` | "video.ready", "transcript.ready", "video.viewed", "comment.created"[] | yes | video.ready (finished uploading), transcript.ready, video.viewed (a counted view) and comment.created. Events of a private video go only to webhooks its recorder made. |


**Returns** `webhook`, `secret` (For checking signatures. Shown only now).

## `update_webhook`

**Pro.** Changes something. Changes a webhook's URL or events, or pauses (active false) and resumes it. Give at least one. The secret stays the same.

**Parameters**

| Parameter | Type | Required | What it is |
| --- | --- | --- | --- |
| `webhookId` | string | yes | The webhook's id (webhookId from list_webhooks). |
| `url` | string | no | Where to post: https, on a public host name. |
| `events` | "video.ready", "transcript.ready", "video.viewed", "comment.created"[] | no | video.ready (finished uploading), transcript.ready, video.viewed (a counted view) and comment.created. Events of a private video go only to webhooks its recorder made. |
| `active` | boolean | no | false pauses deliveries, true resumes them. |


**Returns** `webhook`.

## `delete_webhook`

**Pro.** Changes something; can remove or replace what is there. Deletes a webhook for good: nothing more is delivered to it, retries included. update_webhook with active false only pauses it.

**Parameters**

| Parameter | Type | Required | What it is |
| --- | --- | --- | --- |
| `webhookId` | string | yes | The webhook's id (webhookId from list_webhooks). |


**Returns** `webhookId`, `deleted`.

## `send_test_webhook`

**Pro.** Changes something. Posts a signed webhook.test event (data: &#123; webhookId &#125;) to the webhook now, once, paused or not, and answers what its URL replied, so the user can check their receiver and signature code.

**Parameters**

| Parameter | Type | Required | What it is |
| --- | --- | --- | --- |
| `webhookId` | string | yes | The webhook's id (webhookId from list_webhooks). |


**Returns** `webhookId`, `delivered` (The URL answered 2xx), `status` (The HTTP status it answered; null when nothing answered), `error` (Why nothing answered).
