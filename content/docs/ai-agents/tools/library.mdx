## `get_transcript`

**Pro.** Reads only. Read back what was said in a Recordful video. format: "text" (default), "vtt" (timed captions), "both", or "words" (each word still heard, with its index for cut_clip_by_transcript and when it plays now; indexes never change as words are cut). With query, returns only the moments that mention it (startMs, endMs, text; up to 30) instead of the whole transcript, so search with it first on long videos. Only the person who recorded it, or the workspace owner, can. If it hasn't been transcribed yet (status "none"), start it with transcribe_video.

**Parameters**

| Parameter | Type | Required | What it is |
| --- | --- | --- | --- |
| `videoId` | string | yes | The video's id (videoId from list_videos). |
| `format` | "text", "vtt", "both", "words" | no | "text" (default), "vtt" (with timestamps), "both", or "words" (indexed and timed, for cut_clip_by_transcript). |
| `query` | string | no | Find what was said about this: returns only the matching moments, with times. |
