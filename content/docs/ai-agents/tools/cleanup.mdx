Find and cut long pauses, and cut ums and uhs. 3 tools.

## `get_silences`

**Pro.** Reads only. The silences of minSeconds or more in a Recordful video as it plays now, in seconds of the edited video, found between the lines of its transcript (so it needs one: not_ready means the user must transcribe it on its page first; this never starts one). remove_silences cuts them. Only the person who recorded it, or the workspace owner, can.

**Parameters**

| Parameter | Type | Required | What it is |
| --- | --- | --- | --- |
| `videoId` | string | yes | The video's id (videoId from list_videos). |
| `minSeconds` | number | no | Shortest silence to list, 0.8 to 60 seconds (default 1). |


**Returns** `videoId`, `version` (The edit's version. Pass it as expectedVersion to apply edits only to the edit you read), `minSeconds`, `silences`, `totalSeconds` (How long they last together), `viewUrl` (The video's page on recordful.app), `editUrl` (Where the user edits it).

## `remove_silences`

**Pro.** Changes something. Shorten every silence of minSeconds or more to keepSeconds, the way the editor's Long pauses switch does (that switch then shows them, and turning it off puts them back). Found between the lines of the video's transcript, so it needs one. Replaces silences this cut before. Pass expectedVersion from get_timeline or get_silences to apply only to the edit you read (edit_conflict otherwise). not_ready means the video has no transcript yet: the user must transcribe it on its page first; this never starts one. Only the person who recorded it, or the workspace owner, can.

**Parameters**

| Parameter | Type | Required | What it is |
| --- | --- | --- | --- |
| `videoId` | string | yes | The video's id (videoId from list_videos). |
| `minSeconds` | number | yes | Shortest silence to cut, 0.8 to 60 seconds; the editor uses 1. |
| `keepSeconds` | number | no | How much of each silence to keep, in seconds (default 0.4). |
| `expectedVersion` | string | no | The version get_timeline or get_silences gave. |


**Returns** `videoId`, `version` (The edit's version. Pass it as expectedVersion to apply edits only to the edit you read), `silencesCut` (How many cuts the silences make now (one across two clips is two)), `secondsRemoved` (How much shorter it plays than before this call; negative when it put back more than it cut), `timeline`, `viewUrl` (The video's page on recordful.app), `editUrl` (Where the user edits it).

## `remove_fillers`

**Pro.** Changes something. Cut the filler words (um, uh, a "like" set off by commas) out of the video, as the editor's Filler words switch does (that switch then shows them, and turning it off puts them back). Found in the transcript's words, so it needs a transcript made since filler words were kept. Replaces fillers this cut before; on false only puts them back. Pass expectedVersion to apply only to the edit you read (edit_conflict otherwise). Returns the new version and timeline. Only the person who recorded it, or the workspace owner, can.

**Parameters**

| Parameter | Type | Required | What it is |
| --- | --- | --- | --- |
| `videoId` | string | yes | The video's id (videoId from list_videos). |
| `expectedVersion` | string | no | The version get_timeline gave. |
| `on` | boolean | no | false puts back the filler words cut before. Default true. |


**Returns** `videoId`, `version` (The edit's version. Pass it as expectedVersion to apply edits only to the edit you read), `timeline`, `viewUrl` (The video's page on recordful.app), `editUrl` (Where the user edits it).
