---
title: Record computer audio
description: How to include tab or system audio, and the macOS limitation.
---

- **Tab recording:** enable "Include system audio" in the popup, and in the Chrome picker tick "Also share tab audio".
- **Screen recording:** enable "Share system audio" in the Chrome picker. If the option is missing, update Chrome or switch to Tab recording.
- **macOS:** only tab audio can be captured. Select the Chrome Tab option and make sure tab audio sharing is on.

If the popup warns you to switch modes, follow it: that page only exposes audio to one capture path. Push-to-talk is in the popup options when you want the mic off except while held.
